Three defects the smoke found and fixed:

- `pg.Conn` never set `synchronous_commit = off`, which 07 §7.4 keeps for the recorder; only `journal.py` did. Behind the game's disk traffic every unit commit cost ~14.5 ms and `write_verification` sat at p50 14.5 ms. Set in `_open` so it survives the reconnect-once path: p50 1.0 ms.
- `write_decide` resolved `dict.action` once per offer, 1-2 round trips each, ~180 offers per decision. Now one batched `unnest` lookup plus one upsert-returning for genuinely new keys, cached per process: p50 21.4 -> 10.7 ms. The cache and the other write-path caches are dropped on unit rollback and on reconnect, so an aborted unit cannot leave ids for rows that were rolled back.
- `slot_index`, `rank`, `gnn_rank`, `ggnn_rank` arrive from the collector as floats (`1.0`) and failed the smallint COPY, aborting U2: 82 of 315 decisions in the 8x12 run lost every offer. Whole-number floats now convert, genuinely fractional values raise (12.2 I8). 99 decisions recorded before the fix stay as the 7.4 orphan class (`decision.n_offers IS NULL`, 106 corpus-wide) and are excluded from training by that predicate.
